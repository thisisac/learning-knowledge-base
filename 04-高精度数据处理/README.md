# 高精度数据处理

## 课程内容

学习 Linux 环境、IGS 产品、RINEX 文件、GNSS 误差、GAMIT/GLOBK、基线解算、网络处理和高精度结果分析。

## 课程安排 / 考核

结课以最终报告为主，平时没有单独作业，课堂内容主要服务于最终大任务。每节课需要跟着老师完成 Linux 配置和数据处理步骤，否则后期容易出现调试问题。课程对 Linux 实践很有帮助。
