## 使用说明

先阅读课程文件夹中的 `README.md`，再按需要查阅笔记、报告或代码。课程安排和考核记录仅供参考，以实际授课要求为准。报告统一使用 `bg`、`bg1`、`bg2` 等简短文件名，具体内容见对应课程说明。

PDF、Word 和演示文稿可在文件页面预览或下载；运行代码时，需要按程序配置准备相应软件和数据。部分大型原始数据未收录，现有程序不保证均可直接运行。

资料用于个人学习与复习，第三方课件、文献和软件的权利归原作者，原有许可证以文件内说明为准。
