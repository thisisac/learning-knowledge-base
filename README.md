## 整理原则

- 原始资料只复制，不删除 QQ、微信或桌面中的文件。
- 每门课程使用一个独立目录。
- 课程目录内优先区分：笔记、课件、作业与报告、代码、数据、资料包。
- 微信文件只收录能够根据文件名或所在目录明确判断为课程资料的文件。
- 聊天缓存、缩略图、数据库、发票、个人材料和无关文章暂不纳入。
- 需要进一步人工确认的文件放入 `待确认`，不直接混入课程资料。
