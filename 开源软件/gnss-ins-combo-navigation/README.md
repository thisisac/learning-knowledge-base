# GNSS/INS 组合导航

GNSS/INS 松组合、RTK、伪实时和后处理平滑的 C++ 工程归档。

## 来源

- `src/`：桌面 `大三上/自编程序提交包_精简版/code/GNSSINS`
- `docs/自编程序说明文档.pdf`：原工程说明文档

## 已识别模式

- `rtk`：只运行 GNSS RTK。
- `forward`：RTK + IMU 解码 + 初始对准 + 松组合前向滤波。
- `post`：基于前向结果做离线后处理。
- `all`：完整后处理流程。
- `pseudo-online`：按时间戳模拟传感器播发，逐帧进行预测和更新。
